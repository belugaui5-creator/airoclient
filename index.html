Что делать, если Windows спрашивает подтверждение?

Проверь, что архив скачан из официального источника, распакуй его и запусти start.bat из папки AiroClient.

Почему нельзя запускать start.bat прямо из архива?

Сначала полностью распакуй ZIP. Запуск из окна архива может привести к тому, что клиент не найдёт свои файлы.

Клиент не находит папки mods или runtime?

В полном архиве они лежат рядом с start.bat внутри папки AiroClient. Запусти именно этот start.bat, а не внешний батник-распаковщик. Если папок нет, архив скачался или распаковался не полностью.

Нужна ли Java?

Клиент использует Java 21. Если Java не найдётся, start.bat предложит автоматически скачать её. Для этого нужен интернет.
